# EchoGPT — AI Productivity Ecosystem Redesign

> Frontend Software Engineering Internship Assignment for **AppifyDevs**.

A modern, high-performance redesign of the EchoGPT ecosystem built with Next.js 15, TypeScript, Tailwind CSS, and Framer Motion.

## Overview
- **Landing Page (`/`):** High-converting product showcase with interactive previews, Bento grid features, AI model capabilities, and pricing.
- **Web App Workspace (`/app`):** Focused multi-model chat workspace supporting GPT-4o, Claude 3.5 Sonnet, Gemini 1.5 Pro, and Llama 3.1 with typewriter streaming, Markdown code blocks, and conversation persistence.
- **Chrome Extension Concept (`/extension`):** In-browser simulation featuring both the compact 380px Popup View and the persistent docked Sidebar View (`Ctrl+Shift+E`) with webpage text selection assistance.
